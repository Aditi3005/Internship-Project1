# Internship-Project1

Project Overview
This project demonstrates how to deploy a basic HTML website on an AWS EC2 instance using Apache Web Server.

Services Used
- AWS IAM
- Amazon EC2
- Security Groups
- Apache Web Server
- HTML

Implementation Steps
1. Explored AWS IAM users, groups, roles and policies.
2. Launched an EC2 instance.
3. Configured Security Group inbound rules.
4. Connected to the EC2 instance.
5. Installed Apache Web Server.
6. Created a basic HTML webpage.
7. Deployed the website on EC2.
